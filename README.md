# Micronaut WebSocket

[English](README.md) | [简体中文](README.zh-CN.md)

An adapter for server and client lifecycle annotations and common session APIs from Micronaut WebSocket 5.1.13, whose package coordinates are defined in [module.norm](micronaut/websocket/module.norm). `MicronautWebSocketBindingIntegrationTest` covers official processor endpoint recognition, handshake, asynchronous message sending, and closing.

[Samples](samples/README.md) include a standalone loopback WebSocket echo and a real client verifier.
