# Micronaut WebSocket

[English](README.md) | [简体中文](README.zh-CN.md)

An adapter for server and client lifecycle annotations and common session APIs from Micronaut WebSocket 5.1.13, published as `micronaut:websocket:1`. A runnable pure-Norm Echo endpoint is in `micronaut/websocket/Main.norm`. `MicronautWebSocketBindingIntegrationTest` covers official processor endpoint recognition, handshake, asynchronous message sending, and closing.
