# Micronaut WebSocket

[English](README.md) | [简体中文](README.zh-CN.md)

Micronaut WebSocket 5.1.13 的服务端、客户端生命周期 Annotation 与会话常用 API 适配，发布坐标见 [module.norm](micronaut/websocket/module.norm)。`MicronautWebSocketBindingIntegrationTest` 覆盖官方 Processor 识别端点、握手、异步消息发送和关闭。

[示例](samples/README.zh-CN.md)提供独立的本地 WebSocket Echo 服务与真实客户端验收。
